# Mój Plan

A Polish student diary app: timetable and substitutions, grades, homework, tests, messages, attendance and the user's private notes. The project includes a PWA website, a Windows desktop app and an Android project.

The app UI is in Polish.

## Running on a computer

1. Install Node.js 20 or newer.
2. Run `npm ci` in this folder.
3. Run `npm run dev` and open `http://localhost:4173`.

The eduVULCAN connection is stored locally. The user signs in on the official website, pastes the one-time registration response, and the app creates a local device key. The password is never requested. On a computer the key is saved to `data/vulcan-session.json`; the `data/` folder is ignored by Git.

## Android and GitHub Actions

The project contains an Android/Capacitor app and the `.github/workflows/android-apk.yml` workflow. After pushing the project to GitHub:

1. Push to the `main` branch or open **Actions → Build Android APK → Run workflow**.
2. When it finishes, open **Artifacts** in the workflow run and download the variant for your phone. For most modern phones choose `moj-plan-android-arm64`; for older 32-bit Android choose `moj-plan-android-armv7`. `moj-plan-android-x86_64` is meant for emulators.
3. Unpack the downloaded ZIP and install the APK inside. Do not install several variants at once.

Before the first install of a shared build, create a keystore and add these secrets in **Settings → Secrets and variables → Actions**: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. The workflow then builds a release APK with a stable signature and an increasing version number, so it can be updated without uninstalling. Without these secrets only a debug test APK is built. Do not share it as an updatable version: switching from debug to release requires uninstalling the app on Android, which deletes its local data. Do not change or delete the keystore after sharing an APK.

Creating the key in PowerShell (keep `moj-plan-release.jks` outside the repository; the file is ignored by Git):

```powershell
keytool -genkeypair -v -keystore moj-plan-release.jks -alias moj-plan -keyalg RSA -keysize 3072 -validity 10000
[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path .\moj-plan-release.jks))) | Set-Clipboard
```

Paste the clipboard contents as `ANDROID_KEYSTORE_BASE64`, and save the `moj-plan` alias and your chosen passwords as the remaining secrets. The repository contains no student account, `/api/ap` response, device key or downloaded data. On first launch the APK registers its own key in the app's private folder on that phone. The local API adapter runs inside the app via Node.js for Mobile Apps; the server only listens on the phone's loopback interface. The `dist/` files and copied Android assets are generated by the workflow.

To build or sync manually after changing the website: `npm run android:sync`, then run `gradlew assembleDebug` in `android/` (Windows: `gradlew.bat assembleDebug`). Android SDK and JDK 21 are required. A local signing key can be placed at `android/app/moj-plan.keystore` with its password in the `MOJPLAN_KEYSTORE_PASSWORD` environment variable; without it the debug build uses the standard debug key.

## Features

- Views: Home, Calendar (day/week), Deadlines, Grades, Messages, Attendance and Profile.
- The home screen lets you hide blocks and reorder them.
- The school timetable and substitutions are cached; a change is applied to the right date and lesson.
- A substituted subject is shown as current, with the previous one crossed out below. Being dismissed home stays a readable message, and the cancelled subject is crossed out.
- The class group (1–4) can be set manually. eduVULCAN does not expose the diary number or the group number in the student profile.
- Grades, subject and overall averages and a grade activity chart are shown on the Grades screen. A grade of 1 is marked for correction only if the grade type contains a recognizable test or class test label.
- The deadline list combines homework and tests from eduVULCAN with your own entries, which can be marked as done.
- eduVULCAN data is refreshed every 15 minutes and kept locally for offline use.

## Sources and limitations

- Timetable: `plan.zse.bydgoszcz.pl`; substitutions: `zastepstwa.zse.bydgoszcz.pl`.
- Grades, messages, attendance, homework and tests are fetched via the unofficial eduVULCAN mobile app protocol. The service may change its API and require reconnecting.
- eduVULCAN does not expose the diary number or group split in this student profile, so the group is chosen manually.
- Automatic "needs correction" marking depends on VULCAN returning the grade type name; if it does not, the entry is not marked automatically.
- Private notes, home screen settings and the cache are local to the device and are not synced between phones.

Do not publish the `data/` folder, passwords or one-time registration data. Do not share an APK with an account already connected.
